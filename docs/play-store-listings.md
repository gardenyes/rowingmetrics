## Català (`ca`)

### Descripció breu
```
Mesura ritme, velocitat i distància de rem amb GPS i sensors.
```

### Descripció completa
```
Rowing Metrics és una aplicació per registrar i seguir sessions de rem a l’aigua, pensada per consultar-se amb facilitat mentre remeu.

MESURES EN VIU
• Ritme de braçada (SPM) amb els sensors de moviment del telèfon
• Velocitat actual i velocitat mitjana (GPS)
• Distància acumulada i temps de sessió
• Rellotge local a la mateixa pantalla
• Avís visual si la sessió està activa però no es detecten braçades

PANTALLES
1. Mètriques — Inici / Aturar i lectura en viu
2. Activitats — historial de sessions desades
3. Configuració — sensibilitat, suavització de velocitat i idioma
4. Informació — versió i contacte

HISTORIAL I EXPORTACIÓ
Cada sessió es desa localment en aturar. Podeu revisar, esborrar o exportar l’historial a CSV (compatible amb Excel) a Android.

CONFIGURACIÓ
• Sensibilitat de detecció de braçades (de baixa a alta)
• Suavització de la velocitat GPS (1–8 mostres)
• Idiomes: català, castellà, anglès i francès

PRIVACITAT
Les dades es processen i s’emmagatzemen al dispositiu. No cal compte d’usuari. La ubicació s’utilitza només durant la sessió per a velocitat i distància.

Requisits: GPS i sensors de moviment. A Android, cal permís d’ubicació per a velocitat i distància.
```

## English (`en-US`)

### Short description
```
Track stroke rate, speed, and distance while rowing with GPS and sensors.
```

### Full description
```
Rowing Metrics is an app for recording and following on-water rowing sessions, designed to be easy to read while you row.

LIVE METRICS
• Stroke rate (SPM) from the phone’s motion sensors
• Current speed and average speed (GPS)
• Cumulative distance and session time
• Local clock on the same screen
• Visual alert if the session is running but no strokes are detected

SCREENS
1. Metrics — Start / Stop and live readout
2. Activities — history of saved sessions
3. Configuration — sensitivity, speed smoothing, and language
4. About — version and contact

HISTORY AND EXPORT
Each session is saved locally when you stop. You can review, delete, or export the history to CSV (Excel-compatible) on Android.

CONFIGURATION
• Stroke detection sensitivity (from low to high)
• GPS speed smoothing (1–8 samples)
• Languages: English, Catalan, Spanish, and French

PRIVACY
Data is processed and stored on your device. No account is required. Location is used only during a session for speed and distance.

Requirements: GPS and motion sensors. On Android, location permission is needed for speed and distance.
```

## Français (`fr-FR`)

### Description courte
```
Mesurez cadence, vitesse et distance d’aviron avec GPS et capteurs.
```

### Description complète
```
Rowing Metrics est une application pour enregistrer et suivre des sessions d’aviron sur l’eau, conçue pour être lisible pendant que vous ramez.

MÉTRIQUES EN DIRECT
• Cadence de coups (SPM) via les capteurs de mouvement du téléphone
• Vitesse actuelle et vitesse moyenne (GPS)
• Distance cumulée et temps de session
• Horloge locale sur le même écran
• Alerte visuelle si la session tourne mais qu’aucun coup n’est détecté

ÉCRANS
1. Métriques — Démarrer / Arrêter et lecture en direct
2. Activités — historique des sessions enregistrées
3. Configuration — sensibilité, lissage de vitesse et langue
4. À propos — version et contact

HISTORIQUE ET EXPORT
Chaque session est enregistrée localement à l’arrêt. Vous pouvez consulter, supprimer ou exporter l’historique en CSV (compatible Excel) sur Android.

CONFIGURATION
• Sensibilité de détection des coups (de faible à élevée)
• Lissage de la vitesse GPS (1–8 échantillons)
• Langues : anglais, catalan, espagnol et français

CONFIDENTIALITÉ
Les données sont traitées et stockées sur l’appareil. Aucun compte n’est requis. La localisation sert uniquement pendant la session pour la vitesse et la distance.

Exigences : GPS et capteurs de mouvement. Sur Android, l’autorisation de localisation est nécessaire pour la vitesse et la distance.
```
