# Google Play Console — Release notes (app overview)

Generic “What’s new” / release notes describing how the app works.  
Copy each block into **Release → Release notes** for the matching language.  
Play Console limit: **500 characters** per language.

---

## English — `en-US`

```
Rowing Metrics tracks your rowing sessions on the water.

• Live stroke rate from the phone sensors
• Speed, average speed, and distance via GPS
• Session time and local clock on one screen
• Save sessions, review history, and export to CSV
• Adjust stroke detection and speed smoothing
• Languages: English, Catalan, Spanish, French

Swipe between live metrics, activities, settings, and about.
```
